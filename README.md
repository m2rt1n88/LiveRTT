# LiveRTT 嵌入式调试工作台

从 ELF 的 DWARF 调试信息浏览变量，经 SWD / OpenOCD 读取真实数值，同时接收 RTT 日志。不需要为每个变量新增 print、VOFA+ 类型或数据包。

## 开始使用

1. 双击根目录 `start_debugger.cmd`，保留启动窗口。需要 Python 3.10+ 和 OpenOCD；当前电脑已安装。
2. 第一页「工作空间」填写任意例程或 program 的 ELF 完整路径，点击「加载 / 切换 ELF」。路径输入框可选最近发现的构建产物，也可从「已保存的调试配置」恢复其他 ELF。
3. 搜索或展开变量，添加具体的数值字段。已选变量支持名称、单位、倍率与曲线开关。数量上限 16。
4. 核对连接设置：OpenOCD 程序、板子 / 探针的 `.cfg`、Tcl / RTT 端口。默认沿用当前 CMSIS-DAP / STM32F4 配置。
5. 确认 ELF 与板上固件属于同一次构建，点击「一键连接 SWD + RTT」，再点击「开始采集」。数值和 RTT 在工作空间显示；在第二页「数据曲线」勾选要画的变量。

默认地址为 `http://localhost:8765/#workspace`。端口占用可运行 `start_debugger.cmd --port 8766`。配置文件与 ELF 留在本机，不上传到外部服务。

OpenOCD 已运行时直接复用；没有运行时由网页后台启动。断开、换 ELF 或 Ctrl+C 退出服务时，只关闭网页启动的 OpenOCD，保留外部服务。关闭标签页不会退出 Python 服务。默认配置不暂停、复位、烧录或恢复目标执行；自定义 `.cfg` 应使用正常连接配置。

## 多个 ELF 与配置保存

每个 ELF 路径独立关联一份调试配置，保存在 `data/profiles.json`。相同文件名位于不同目录时，也会分开保存。切换前会保存当前设置；切换后恢复变量、名称、倍率、单位、绘图选择、采样频率、时间窗口、OpenOCD 连接设置与可选模块绑定。

修改后约 650 ms 自动保存，可点击「保存配置」立即保存。顶部显示保存结果；保存失败会明确提示，切换 ELF 会等待保存成功。写入通过临时文件原子替换，原配置库损坏时保留原文件并报错。

重新编译同一路径的 ELF 仍会复用配置，重新解析地址与类型，不保存旧 RAM 地址；失效路径保留并标记，避免丢掉手工设置。板上代码与 ELF 抽查不一致时拒绝采样。硬件连接与版本确认不会随配置自动恢复。

配置可导出 / 导入 JSON v2；也兼容以前导出的 v1 变量配置（含 `elfHint`）。换电脑后可编辑导出文件的 `elfPath` 与连接路径，再导入。每个 ELF 一份配置，同一时刻连接一块板。

云台 / 底盘绑定也可直接写入 JSON，无需逐项在网页填写。推荐导出当前 ELF 的配置，编辑后再导入；从零开始可复制 [空配置模板](docs/examples/motion-profile.json)。变量路径、电机映射及程序接口见 [配置文件说明](docs/profile-configuration.md)。

当前浏览器会话内，切换 ELF 会保留各自普通变量采样历史和 RTT 文本；同一路径 ELF 内容变化时丢弃其旧会话历史，防止混用数据。电机、云台和底盘监视在重新加载 ELF 或重新连接后重新积累历史。刷新前请导出 CSV / 电机 JSON / RTT 日志。配置会保存在磁盘，采样历史不自动写盘。

## 页面与模块

- **工作空间**：选择 ELF / 恢复配置、连接硬件、变量浏览器与当前读数、RTT 日志。
- **数据曲线**：选择已选变量绘图、不同单位独立纵轴、时间窗口、指针读数、CSV 导出。切页共用同一采集会话。
- **电机监视**：位于云台 / 底盘之前。启用后扫描 CAN 电机，按总线选择采集对象，无需逐字段绑定。总览在线、模式、反馈、目标、output、电流与温度；重点电机显示角度指针、目标/反馈趋势、输出/PID 分解、偏差和状态事件。选择与筛选按 ELF 保存，采样可导出 JSON。支持仓库内 DJI / DM，以及可定位的 CyberGear 对象；详见 [电机监视说明](docs/motor-monitor.md)。
- **云台监视**：一张斜视图合成 Yaw / Pitch 双轴姿态，目标与反馈叠加、转向、限位、误差趋势、CAN / 模式 / 使能 / 输出和状态事件。支持电机映射、方向、减速比、零点与自定义 IMU / 控制变量。
- **底盘监视**：可切换 Mecanum / Omni 四轮构型，显示平移和转动方向、四轮反馈 / 目标 / 输出、朝向及趋势；悬停车轮查看实时电机数据，点击固定窗口。支持实测速度绑定或四轮在线时的理想运动学推算。
- **整车状态**：独立开关，复用云台与底盘绑定，在一张图中还原机构姿态并叠加目标；六电机数据窗、最终瞄向误差和旋转补偿趋势帮助排查整车联动。航向支持实测变量或明确标记的轮速相对推算；详见 [整车监视说明](docs/vehicle-monitor.md)。新增此模块后需重启 Python 服务再刷新网页。

监视入口常驻左侧，进入各自页面后启用；新配置默认全部关闭。电机绑定、构型和标定按 ELF 独立保存，各模块采样互不依赖开关。目标监视已删除，旧配置中的普通变量保留。云台 / 底盘的操作、坐标与单位说明见 [图形监视说明](docs/motion-monitor.md)。

原「串口工作台」在这版统一为「数据曲线」，数据源为已连接的 SWD 变量；旧 CSV / JSON 串口映射和模拟车辆演示已从当前项目移出。旧版本在项目外的归档中保留。

快捷键：`1` 工作空间，`2` 数据曲线。进入浏览器后台会暂停内存采集，返回后手动继续。

## 目录

~~~text
debug_web/
  backend/             Python 服务：ELF、OpenOCD、RTT、会话、配置存储
  frontend/
    index.html         页面骨架
    assets/css/        样式
    assets/js/         页面逻辑、API、配置与曲线
  tests/               Python / JavaScript 测试与测试说明
  data/                本机持久化调试配置，不对外提供静态访问
  docs/                架构说明与页面截图
  .deps/               已安装的离线 Python 依赖（可选）
  start_debugger.cmd    Windows 启动入口
  requirements.txt     Python 依赖
  package.json         无前端依赖，提供 Node 测试入口
  README.md
~~~

开发启动：`python -m backend.app --no-browser`。固件工程不在默认相邻目录时传 `--firmware-root "工程目录"`；配置库可通过 `--data-dir "数据目录"` 指定。

## 当前支持范围

32 位 ARM ELF，需包含 DWARF（构建开启 `-g`）。支持固定地址全局 / 静态变量、结构体 / 类、普通继承、指针字段、一维数组及布尔 / 整数 / 枚举 / 浮点数。任何例程 / program 均可自定义变量，但内存范围和自动 RTT 搜索目前针对 STM32F4 SRAM / CCM，换芯片需相应扩展读取范围和 RTT 设置。

变量路径不执行 C++ 函数、赋值表达式或任意表达式；电机监视另提供白名单内运行参数写入、读回确认、角度目标拖动和 DJI 电机使能开关（暂停采集也可操作），见 [电机监视说明](docs/motor-monitor.md)。局部栈变量、寄存器变量、位域、虚继承、动态 / 多维数组不在当前范围。空指针、非法地址、NaN / Inf、单通道错误会显示缺失，不补模拟值。

电脑轮询支持 5 / 10 / 20 Hz，实际速度依通道数和探针而异，不等于板端控制周期。不同字段不是原子快照。图表保留最近 10 分钟、最多 12,000 帧；RTT 保留 1,500 行。CSV 包括原始值与显示值，64 位整数原始文本保留精度。

RTT 搜索沿用原配置：SRAM `0x20000000` 起 `0x30000` 字节，上行通道 0。固件没有 RTT 控制块或输出时，日志不可用或为空；变量读取仍可使用。多个网页共用一个后端会话，建议一次只打开一个调试页面。

## 验证

所有测试代码位于 `tests/`。在项目根目录执行：

~~~powershell
python -m unittest discover -s tests -p "test_*.py" -v
npm test
~~~

测试需要 Python ELF 解析依赖；Node 仅用于前端纯逻辑测试，无需 npm 安装。测试内容和板端验证记录见 `tests/README.md`。

构型扩展：云台和底盘页面支持选择模板、编辑构型 JSON；常规 / 大小 Yaw / 串联折叠头、四轮 / 差速 / 三轮全向共用框架，各 ELF 保留独立机构快照与绑定。参见 [构型模板与扩展](docs/mechanism-configuration.md)。
