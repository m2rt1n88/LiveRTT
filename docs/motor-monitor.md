# CAN 电机监视

电机监视位于云台、底盘之前，默认关闭。它使用当前 ELF 的类型布局读取固件对象，不需要新增打印或逐字段绑定。

## 使用

1. 在工作空间加载本次烧录的 ELF，连接 SWD + RTT。
2. 进入「电机监视」，打开启用开关，点击「扫描 CAN 电机」。启用与连接成功时也会自动扫描。
3. 按 CAN 筛选，勾选电机或「全选当前总线」，点击顶部「开始采集」。不需要添加普通变量。
4. 点击某台电机的「查看」，观察指针、反馈与目标曲线、输出、PID 分解、目标偏差与状态事件。
5. 用「导出采样 JSON」保存最近的电机采样和事件。选择、CAN 筛选、重点电机及监视模块开关随当前 ELF 自动保存；不保存或恢复电机使能状态。
6. 在「电机调参与角度控制」编辑 PID、目标或运行前馈，点击对应组的「应用修改」（输入框支持 Enter）。草稿不会被实时采样覆盖。
7. 展开「角度盘与目标控制」，角度环下拖动橙色目标指针，绿色显示实际反馈。最多每秒下发 8 次；慢探针只保留最新待发目标，松手发送最后目标。也可输入度数，或聚焦指针后按方向键调整 1°、Shift + 方向键调整 10°，Esc 清除尚未发送的目标。
8. 在列表「模式 / 使能」列或调参面板右上角切换「电机使能」。这与页面的监视开关独立：关闭监视只停采集；关闭电机使能才改变板端软件使能状态。

## 电机使能

目前支持 DJI：从 DWARF 验证 state_.enable 是可变的单字节 bool，专用接口只写该字节，不改动相邻字段，并重新读取状态。关闭时取消未发送的角度目标，等待已发送的参数/目标请求结束后再失能；操作中禁止新的目标写入。连接且通过 ELF 代码抽查时，暂停采集也可使用开关，操作时会重新读取板端。关闭不要求反馈在线或旧模式仍匹配；开启要求当前反馈在线且模式一致。

DJI 固件在后续 CalcOutput 中归零输出，并按驱动逻辑清积分；这是软件失能，不是硬件急停或电源断开。重新开启继续执行板端现有目标。刷新、重连和配置恢复不会自动使能；固件重新使能或覆盖该值时，以后续读数为准。写入失败、读回失败和被固件覆盖会明确提示，开关不会提前显示操作成功。

DM / CyberGear 的使能方法还需要发送设备命令，不能只改 bool；界面显示不可操作和原因，待固件命令链路接入后支持。

## 电机写入

DJI 支持运行中的 ConstrainedPID 增益、输出/积分限幅、死区和滤波系数，以及当前模式的角度/速度目标、速度前馈与 raw 电流前馈。两环还支持 ScalarA / ScalarB 与六个算法开关：积分限幅、微分先行、梯形积分、输出滤波、变速积分、微分滤波。CURRENT 模式不开放目标写入。DM 支持 MIT 的 Kp/Kd/力矩前馈、MIT/POS_VEL 的角度目标和各模式速度设定；范围取自 config_，缺少量程就不开放，POS_VEL 的速度是非负上限。CyberGear 没有可定位的持久控制目标，暂不支持写入。

参数接口只开放 ELF 中明确可定位、非 const/atomic、对齐的 float32 参数，以及两环限定的 uint8 PID 特性位；使能使用上面的专用 bool 接口。特性位仅允许修改 0x77，保留比例先行（未实现）与故障回调开关，电机本身的控制模式仍不开放写入。后端重新解析对象并核对当前 ELF、对象地址、控制模式、字段白名单和范围，参数使用单次 32 位 RAM 写入并立即读回。整组参数顺序写入，部分失败会记录并停止，已写入参数不自动回滚。

算法开关与 A/B 必须在软件失能时应用，后端在每次写入前复查失能状态和特性位；开关需携带编辑起始值，过期草稿会拒绝。整组先写浮点值，再写开关；变速积分要求最终 float32 值 A > 0、B ≥ 0、A+B 不溢出。遇到读回不符立即停止。整个过程仍不是固件事务，软件失能可能被上层任务覆盖，不承诺清空微分 / 滤波历史。当前固件微分先行为 **+Kd × Δ测量值**；滤波使用 α×当前值+(1−α)×历史值，α=1 直通、α=0 保持历史值，取消对应开关才是关闭滤波。

角度盘使用 DJI 输出轴坐标和底层目标坐标，不再次执行 SetTarget 的 INVERTED 变换；DM 使用转子坐标并遵守 angle_max。ABSOLUTE 为单圈，连续模式以当前目标起算并跨圈累计。输入度数会转为 rad 写入。需要连接、持续采集和新样本；目标还需要在线且使能，DM 额外检查使能反馈。暂停、切页、隐藏、断开、切换电机/ELF/模式会清除未发目标。已经开始的请求无法撤回；取消拖动不会停机，固件继续执行最后目标。

直接写 RAM 不调用 Reinit、SetTarget、Enable/Disable 或清积分方法；使能标志的后续行为由固件控制循环执行。不更新模式预设，也不保存到 Flash。上层任务可能覆盖目标/前馈，切换模式可能重载 PID；读回确认只证明当次值一致。写入记录保留当前电机最近 50 条，切换电机或会话时清除。

关闭监视会停止这部分电机采集，保留选择；工作空间与普通变量曲线继续。离线可看静态候选，运行时注册表需要连接后才能展开。失效选择保留并提示，重新构建后重新扫描。

## 能看到什么

- 总览：CAN 归属、对象类型、路径、RX / TX ID、online、反馈龄、软件使能、模式、theta / omega、目标、output、电流、温度。
- DJI：转子和输出轴反馈，按当前控制模式区分角度目标 rad、速度目标 rad/s、电流指令 raw；最终输出与速度 PID 的 P / I / D；当前输出限幅比例与 PID 接近限制提示；驱动自身报告的堵转状态。CURRENT 模式优先于角度/速度环，与固件逻辑一致。
- DM：MIT / POS_VEL / VEL 模式、转子位置/速度设定、力矩反馈与前馈、MOS / 转子温度、使能反馈和故障码。偏差按转子反馈计算，力矩前馈不称为总输出。
- CyberGear：反馈角度、角速度、力矩、温度、模式、反馈状态和原始故障码。此驱动没有持久化的目标 / 输出指令，页面显示缺失，不猜测发送缓冲区的含义。
- 重点电机：同单位曲线、目标减输出轴反馈偏差、绝对角度模式下的最短角差、原始字段展开。
- 状态事件：online、使能、模式、故障、读取失败的变化，保留 150 条，页面显示最近 30 条，导出含全部保留事件。

DJI 温度使用驱动实际更新的 CAN 字段 state_.raw_temperature；state_.temperature 原样保留在原始字段里，但当前驱动没有更新它。无法解析、空指针、NaN / Inf 均不会补成零。

## AI 调参最简版与规划

重点电机曲线下已有「AI 调参建议 · 简版」：填写目标和试验说明，选择最近 10 / 30 / 120 秒，生成可复制或下载的参数与原始采样材料；自行发给 AI 后将回复粘贴到页面，可一起下载。材料生成不执行任何电机操作。实时刷新保留材料和输入，切换电机 / 会话会清空；刷新前请下载。详见 [最简版使用说明](ai-quickstart.md)。

完整后续设计将试验记录、采样质量、AI 分析和建议差异放在重点电机曲线下；手动算法开关、A/B 和滤波已在调参区开放；agent 仍只提交建议，不执行写入。计划中的 agent 只读数据并提交草稿，由操作者在网页应用。上述完整功能尚未实现；最简版使用独立 motor-ai-brief 格式，现有导出也尚不等于完整 AI 试验包。

详见 [参数能力字典](ai-parameter-capabilities.md)、[试验格式与合成示例](ai-trial-format.md)、[调参流程与接口边界](ai-tuning-workflow.md)。

## 发现与读取边界

后端 backend/motors.py 从 DWARF 识别继承布局。DJI 的 groups_ 分组表、DM 的 instances_ 实例表覆盖堆上注册对象，同时搜索全局/静态电机、对象成员和一维数组。扫描不遍历任意指针图、不解析 STL 容器；CyberGear 支持 ELF 中可定位的静态对象/指针。通用搜索最大深度 5、一维数组最多 64 项、候选最多 256，单次最多采集 64 台。无法定位的对象仍可通过变量浏览器观察其可解析字段。

这是固件对象列表，不能发现固件没有注册、没有调试类型信息的物理 CAN 设备；扫描不发送 CAN 探测帧。写入目标后由固件控制任务生成 CAN 输出。型号只按可用的静态类型显示，只有基类注册指针时显示基类名。

online 使用 ConnectionDriver 的 last_uptime_、online_threshold_ 和 HAL uwTick，保留未收到反馈 / 超时 / 未知时钟 / 读取失败的区别。心跳在读取时钟附近再次读取，减少整块对象读取延迟导致的假超时；如果两次读取间收到新心跳，反馈龄显示 0 ms。uint32 时间回绕按模运算处理。采集暂停后明确标注历史状态，不根据转速为零猜测离线。

字段偏移每次加载 ELF 重新解析，不保存地址。通过受限 SRAM 读取获取数据，单次最多 512 字节；较大对象分块读取。Flash 代码抽查通过后才允许采集与受限电机写入，不调用固件函数、复位或烧录。

电机工作区左侧独立滚动编辑，右侧四图按 2×2 并排：DJI 为角度、速度、驱动指令与速度环 PID、电流。可点击「展开工作区」占满窗口，普通视图也可拖动工作区右下角增加高度。电机列表收起在工作区上方，诊断与原始字段放在下方。

「驱动指令与速度环 PID · raw」绘制 output_、omega_pid_ 的 P/I/D，以及仅在 CURRENT 模式显示的直通目标。raw 为驱动原始指令刻度，不是实际电流 A 或力矩 N·m；实测电流见「电流反馈」。速度环未启用、CURRENT 旁路或软件失能的历史帧不绘制速度 PID 分量与速度环目标，避免把保留值当作正在运行的环路。滤波、限幅、前馈、取整及跨更新读取会使输出不等于 P+I+D；即使环路启用，无新反馈时存储值仍可能保持。图中「说明」可展开解释。

全部字段按反馈、目标与状态、速度 PID、角度 PID、驱动与其他字段分组；字段与当前值在同一表格行内对应，带表头、横线和交替底色。数值保留采样精度，小量不再被五位小数舍入为零；读取错误单独标色，保留未知字段。这里是只读原始存储值，字段存在不代表可写或正在生效。

曲线默认跟随最近 30 秒，内存保留最近 120 秒且最多 600 帧。四图共享时间轴：滚轮以指针为中心缩放，拖动平移；Shift + 滚轮 / 拖动（或在左侧 Y 轴操作）单独缩放 / 平移纵轴。「Y 自动」恢复该图自动量程，「跟随最新」恢复时间跟随，「全部历史」查看当前保留窗口。双击图形恢复时间与当前图 Y 轴；键盘 +/- 缩放、左右方向键平移、Esc 复位。悬停显示最近实际采样点的同步十字线、毫秒时间和各曲线数值，缺失值显示 —，曲线在缺失或长采样间隔处断开，不插值补点。缩放与编辑草稿在实时更新时保留；切换电机 / 对象 / 会话重置图形视口。Y 轴带多级数值与横向网格，自动量程按可见窗口数据计算。重新加载 ELF 或重新连接后电机历史重新开始，设置仍恢复。实际刷新速度受探针、所选电机数量和内存读取时间影响；这是 SWD 轮询观察，不是原子快照或控制周期同步采样。温度和物理量的有效性以驱动实际更新的字段为准。只有固件故障位才被明确称为故障，输出接近限制仅作为排查提示。
