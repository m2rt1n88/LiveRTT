# AI 调参最简版

2026-11-16：已实现“准备分析材料 → 手动发送给 AI → 粘贴建议”。不需要模型 API、MCP 或安装 Skill；页面不会发起模型请求。建议仍由操作者核实后在现有参数区手动应用。

## 使用

1. 重启本地 Python 服务并刷新网页，以便服务允许加载新增 motor-ai.js。
2. 在电机监视选定重点电机，采集实际动作。曲线下出现「AI 调参建议 · 简版」。
3. 输入目标；可补充机构、负载、动作过程、认可的参数范围以及目标是否由上层任务更新。
4. 选择最近 10 / 30 / 120 秒，点击「生成分析材料」。窗口相对最后保留样本，实际覆盖时长与帧数会显示；仍受现有 120 秒 / 600 帧上限约束。
5. 展开完整材料预览，点击「复制给 AI」粘贴到你正在使用的 AI；也可下载 .txt 交给能读文件的 agent。剪贴板不可用时自动选中材料，按 Ctrl+C 手动复制。
6. 将 AI 回复粘贴到页面的建议框，结合当前板端读数，在上方现有参数区手动调整。可下载材料与回复留作记录。

生成材料和粘贴建议不写 RAM、不使能、不切换模式。暂停采集后也可生成，但材料会注明样本年龄。生成的材料保持不变，实时采样不覆盖编辑内容；重新生成会清除旧回复，切换重点电机、对象或会话会清空关联。数据只保留在浏览器内存，刷新前请下载。

## 材料内容与限制

格式为 livertt.motor-ai-brief/1，与完整 [trial 设计](ai-trial-format.md) 区分：它是已有保留数据的分析简报，没有受控试验边界、执行确认或参数写入事务。

- 当前、窗口开始和结束的已读字段；两环增益、限幅、死区、特性位、滤波系数、前馈、目标及相关反馈。不存在的必需字段明确为 null，失败字段另记。
- 重点电机原始序列、字段单位、观测到的参数 / 模式 / 使能变化、主机采样间隔、缺失数和数据年龄；全部保留点直接导出，不插值或降采样。主机时间不能当作板端控制周期。
- 后端现有可写字段和实现范围，工程范围仍标未知。人工说明可补充认可范围；没有充分证据时提示模型只给调整方向、补采要求和验证步骤。
- 已审阅源码的特殊 PID / 滤波语义，同时声明尚未证明与当前运行固件一致。不给低率数据计算假精确的超调、稳定时间或振荡频率。

自动字段使用固定白名单，不包含 ELF 路径、对象地址、回调指针、原始错误文本或 token。用户输入的目标 / 说明会原样进入材料，因此外发前仍应预览。回复作为 textarea 纯文本展示，不解析 HTML、执行代码或自动填入可写草稿。
