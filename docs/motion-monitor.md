# 云台与底盘图形监视

当前构型系统已支持可编辑关节树和可变轮组；新增字段、模板切换及扩展方法见 [构型模板与扩展](mechanism-configuration.md)。下文常规双轴 / 四轮字段继续兼容。

从左侧进入对应模块，在模块页面启用。两个模块与电机监视独立；无需打开电机监视，也不需要将电机几十个字段加入首页。电机采样与其他模块合并、按路径去重，总计最多 64 个不同电机，普通变量仍最多 16 个。关闭模块停止它的专用电机采样，保留绑定与标定；其他模块仍使用同一电机时继续采集。

## 云台

展开「构型、电机映射与坐标标定」，扫描电机后分别选择 Yaw、Pitch。反馈采用驱动输出轴角度 / 速度（DJI 的 output_shaft 字段，DM / CyberGear 为其驱动角度），目标按电机实际控制模式读取；速度 / 电流模式不会冒充角度目标。

电机标定：`姿态 = sign × 输出轴角度 ÷ ratio − zero`。zero 在界面使用度；内部计算使用 rad。ratio 是机构额外减速比，DJI 驱动已计算的减速比不应重复填写。电机目标进行同样变换；速度只应用方向与减速比。Yaw 可选择最短角差；物理限位、跟踪偏差阈值用于网页提示，不会修改固件控制限制。

云台使用一张斜视姿态图，同时合成 Yaw 朝向与 Pitch 俯仰：底座表示固定参考系，炮管随两轴反馈联动。正 Yaw 从上方看逆时针，正 Pitch 抬头。绿色为反馈，橙色虚线为目标；完整炮管姿态需要对应两轴均有数据，缺失轴会明确提示，不用零角度代替。画面随采样改变角度，不播放模拟运动。两轴读数、转向、限位、误差趋势、CAN 在线、软件使能、控制模式、output 和状态事件辅助区分失能、掉线、跟踪偏差、固件 PID 堵转与输出接近限制。偏差提示只表示观察到偏差，不断言机械故障。

图中 Y / P 电机热点支持悬停即时查看 Yaw / Pitch 电机，显示原始输出轴 θ / ω、姿态反馈 / 目标、误差、在线、模式、使能、output、电流 / 力矩、温度与故障。点击可固定，Esc 关闭，也可用 Tab / Enter 操作；窗口随采样更新，暂停或超时后标为历史值。使用自定义姿态时，窗口注明姿态来源，同时保留原始电机数据。

Yaw 图形使用水平转盘，Pitch 使用横向转轴，不再将两轴画成竖直堆叠的圆点。右侧俯视方向盘以蓝色表示车头、绿色表示反馈、橙色虚线表示目标，并显示相对车头左 / 右转角。开启 Yaw 最短角差时，大号读数显示 ±180° 方位；累计角仍在提示、趋势及电机数据窗中保留。

使用 IMU 或程序自身控制量时，展开「自定义变量绑定」，直接添加并选择相应字段。自定义绑定优先于电机值，遵循普通变量的倍率 / 单位，视为已经标定到最终参考系，不再叠加电机零点与减速比。支持 rad / rad/s、deg / deg/s、° / °/s；未填写单位时采用模块默认单位，其他量纲应先用倍率换算并修改单位。

为防止把编码器坐标误当作 IMU 坐标，绑定自定义姿态后，对应目标和角速度也需明确绑定；不会自动沿用电机坐标中的目标与角速度。绑定字段读取失败时显示缺失，保留曲线断点。仓库 `Gimbal::pitch_angle_ / yaw_angle_` 是含偏移的控制目标，`UpdateIMU` 会进一步转换电机目标；请按照实际控制链选择比较对象。

## 底盘

选择 Mecanum（X 滚子麦克纳姆轮）或 Omni（四轮 ±45° 切向 X 型全向轮），绑定左前 FL、右前 FR、左后 BL、右后 BR。依据车辆前进方向判定左右；电机不能重复绑定多个轮位。配置轮半径、半轴距、半轮距、每轮正方向及额外减速比。

坐标与轮序以嵌入式仓库为准：

- `boards/components/include/chassis.h` 的 `FourWheel` 顺序为 front_left / front_right / back_left / back_right，即 FL / FR / BL / BR。
- `programs/Neo/gimbal/src/chassis_task.cpp` 中 D−A 对应正 vx，W−S 对应正 vy，E−Q 对应正 vt：+vx 向右、+vy 向前、+vt 俯视顺时针。
- `boards/components/src/chassis.cpp` 的 `SetSpeed` 使用原始电机符号：FL = y+x+t(1−offset)，FR = −y+x+t(1−offset)，BL = y−x+t(1+offset)，BR = −y−x+t(1+offset)。四轮同正速表示顺时针旋转；前进时左轮正、右轮负。默认 sign=1 保留此约定，不将右轮自动取反。

Omni 的四个轮心位于四角，轮的滚动方向与中心连线相切：FL / BR 与 FR / BL 分别使用相反的 ±45° 安装角。底盘俯视图和整车斜视图共用同一轮位 / 方向定义。几何图是构型示意，物理速度换算由所填半轴距 / 半轮距决定。旧配置中的 rl / rr 读取时自动映射到 bl / br，保留电机路径、方向与减速比；已有方向设置仍需对照仓库核实。

图中机体固定于机体系，绿色矢量表示反馈 / 推算的平移方向，旋转箭头表示角速度方向；橙色虚线表示指令，箭头长度按所设满量程限幅。单独的朝向指针使用已绑定的实测 heading；不会把速度积分成虚构轨迹。四轮表格显示在线、模式、反馈 / 目标和输出；趋势按 m/s、rad/s 分开展示。

鼠标移到任一车轮上，会立即出现该轮电机数据窗，Mecanum 与 Omni 均支持。窗口显示绑定路径、CAN / 型号、在线、模式、使能、输出轴 θ、按轮位方向与额外减速比换算的 ω / 速度目标，以及可用的角度目标、output、电流、力矩、温度、反馈间隔和故障。未提供的字段显示缺失；读取错误单独提示。窗口随采样更新，暂停或超时后标明历史值与采样时间。点击车轮可固定窗口，再点一次或按 Esc 关闭；也可用 Tab 聚焦车轮、Enter / 空格固定。

未绑定实测速度时，四轮在线且有有效反馈才能做理想无滑移推算；任一轮缺失 / 离线就停止推算。几何与减速比错误会导致结果错误，推算不能测出真实打滑或位移。支持的 Omni 为固定四轮 X 布局，三轮、可转向轮或其他安装角暂不适用。

实测速度绑定需换算到 m/s，实测 vt 角速度为顺时针正的 rad/s 或 deg/s。航向 heading 与云台 Yaw 采用逆时针正，整车合成时显式换算 vt 的符号。

绑定仓库 `Chassis::chassis_vx / chassis_vy / chassis_vt` 到指令栏时，在「自定义指令单位」选择「仓库 Chassis::SetSpeed 原始量」。这些是限幅前的轮速混合量，不是实测 SI 速度。网页按半径 R、A（Mecanum=1，Omni=1/√2）与 K=(半轴距+半轮距)×A 换算：vx=x×R/A，vy=y×R/A，vt=t×R/K。原始量不会按 deg/s 再转换一次；已选变量倍率仍生效。已换算成物理量的绑定则保留默认「物理量 m/s、rad/s」。该选项只影响显式绑定的指令，不影响轮目标推算。

「旋转中心偏移 chassis.offset」对应仓库 offset，默认 0。轮速反解使用相同的偏移补偿。驱动限幅、功率限制与滑移可导致原始指令和轮速反馈有差异；网页不把偏差直接判作故障。

## 配置与历史

每个 ELF 保存各自的开关、构型、轴 / 轮绑定、方向、比例、零点、限位、阈值和自定义字段。新配置默认关闭；旧目标监视设置会忽略，原普通变量仍保留。所有绑定保存变量路径，不保存 RAM 地址。

图形历史最多 60 秒 / 600 帧，曲线显示最近 30 秒，事件保留 80 条并显示最近 25 条。重新加载 ELF、重新连接或修改标定 / 绑定时清空相应图形历史，避免跨来源比较。暂停或超过 2 秒无更新时明确标记历史状态；采样时间冻结，页面不自行旋转。SWD 字段跨多次读取，不是控制周期原子快照。
